Tips

  • Search first. If a discussion already exists, link that instead.
  • Use a clear title so it is easy to find later.
  • Choosing a post type gives you a checklist for it.
  • You can use Markdown for links, lists and code.
  • Put two or more images on their own lines to make a gallery - click any image to view them full size.
  • Type @ to mention someone (they get notified) or [[ to link an addon.
  • Resize an image with ![caption|2](url) (1 small – 4 full width). A Streamable, YouTube or Vimeo link on its own line embeds as a player — add |1–|4 to the link to resize it.
